# Lesson 10 Who is she? — 3학년 영어 수업 웹앱

`index.html`을 크롬에서 두 번 클릭해 열면 됩니다(`assets/` 폴더와 같이 두세요).

| 화면 | 내용 |
|---|---|
| 0 시작 | 학습 목표, 핵심 문장, 오늘의 순서 |
| 1 이야기 영상 | “교과서 홈페이지에서 확인!” 안내 + 1회차(자막 없이)·2회차(자막 켜고) 체크 |
| 2 대본 | 중요도 3단계 색: 빨강 핵심(Who is he/she? – He’s/She’s my ~) · 파랑 함께 익힐 표현 · 회색 이야기 흐름 |
| 3 칭찬 표현 | 아빠의 “Well done!” + 생활 칭찬 표현 12개 + 상황 뽑기 |
| 4 Talk and Read | 110쪽 사진 묻고 답하기 |
| 5 어휘·가족 사진 | ① 어휘 미리 익히기(가족·형용사 짝·무지개 7색·clothes/hair, 사진 묘사와 게임 공통) ② 7명 가족 그림(SVG, 한 사람에 한 색 단색 옷) + 형용사 반대말 짝(old↔young, tall↔short, long↔short) + 옷 색깔 문장(My clothes are 색깔.) → 문장 고르고 사진에서 누구인지 누르기 |
| 6 미스터리 상자 | 10상자 게임(⭐ 큰 힌트 3 · 📷 사진 힌트 2 · 💡 작은 힌트 1 · 특별 2(🙅 탈락시키기·😇 살리기) · 꽝 2(Oops·엉뚱), ‘가족 사진 보기’ 버튼 / 개별 진행: 한 명씩 상자 번호를 영어로 외치기(“Seven, please!”, 상자에 one~ten 표기) → 상자 열기 → 아는 친구가 “정답!” → 선생님 “Who is he or she?” → 대답 / 모은 힌트 배너) |
| 7 정리 | 선생님이 카드를 누르면 가족 사진 속 한 명이 무작위로 나옴(6명을 다 돌면 다시 섞음) → 다 함께 “Who is he/she?” → “He’s/She’s my ~.” (가린 말풍선을 눌러 확인·듣기) |

## 조작
- 화면 이동: ◀ ▶ 버튼, Page Up / Page Down(프레젠터 리모컨)
- 영어 문장·단어를 누르면 브라우저 음성으로 읽어 줘요.

※ 교과서 그림·사진과 대본(`assets/` 폴더, 대본은 `assets/textbook.js`)은 저작권 때문에 GitHub·Railway에 올리지 않아요. 배포본에서는 그림 자리에 그림말 카드가, 대본 화면에는 "교과서를 함께 봐요" 안내와 핵심 문장 틀만 보여요.
